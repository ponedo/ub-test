# Phase 1 milestone 2: fixed-placement single-layer MoE prefill
Authorized by user, 2026-10-15 06:30 UTC; base 82fd5e0.

Goal: validate Dispatch -> serialized per-NPU Expert Compute -> Combine, with no balancing, replication, reroute, relay optimization or planner.
Topology: one central UB switch, one 100 Gbps / 20 ns link per NPU; fixed single shortest path. Not CM384. RTP connections provisioned only for used remote pairs. Explicit application byte payload on every remote WQE. Local assignments use explicit zero-time local copy (no modeled memory contention).
Compute: per destination NPU wait for ALL its assigned token contributions; execute active experts serially using aggregate token counts, others execute in parallel. 2-matmul MLP cost 4*model_dim*ff_dim FLOP per assignment (FMA counts 2); no numerical MLP. For each active expert duration_ps = setup_ns*1000 + ceil(tokens*4*model_dim*ff_dim*1e6/(peak_GFLOPs*util_permille)). One NPU's experts share one effective compute budget. No compute for zero load. Synthetic result is deterministic transform of received bytes. Combine validates byte identity and waits all K unique experts per original source token.
Cases: sequential 4 NPU uniform, 8 NPU uniform; only if both pass run 64 NPU uniform; then 4 NPU skew, zero-token, all-local, and invalid configurations. Defaults E=2*N, T=2*N, K=2, dim=256, ff=1024, dtype_bytes=2, TA=256, peak=1000 GFLOPs, util=500 permille, setup=100 ns, seed=20261015. Fixed placement expert % N; generator can accept explicit placement and token mapping. All runs retain full bytes, not sampled/length-only shortcuts.
Predictions: exact T*K assignments and 2 transfers per assignment; local+remote payload bytes conserved; all computed/combined output identities match; skew may increase max NPU compute load. No comparative performance claim. Failure signals: missing/corrupt/early/duplicate events, wrong conservation, unsupported config, invalid build. Stop on 4/8 correctness failures before 64.
Artifacts: config.json, input.txt, assignments.csv (synthetic raw trace), events.csv, native UB traces, summary.json, console and build/tool logs, tests. Strict explicit-exception verifier in normal and -O Python. Existing PoC regression unchanged, output to separate directory.
